# Sunarae 0.5.1 (20)

## 변경

입력기 전환 시 커서 아래 파란 표시 안이 비어 있다는 보고에 따라 아이콘 등록 설정을 보완했다.

- `TISIconIsTemplate`: 투명 배경의 검은 아이콘을 시스템 표시 색에 맞추도록 지정.
- `TISIconLabels.Primary`: `순` 표시 문자열 제공.
- `tsInputMethodAlternateIconFileKey`, `tsInputMethodPaletteIconFileKey`: 기존 `MenuIcon.tiff`를 명시.

앱·입력 소스 ID, 아이콘 그림, 한글 조합과 키 처리 코드는 바꾸지 않았다.

## 확인

2026-10-03 이 Mac에서 확인했다.

- 기존 TIFF의 16×16·32×32 이미지에 실제 글자 픽셀이 있음을 확인했다. 빈 이미지 파일은 아니었다.
- 빌드·서명 검증, plist 형식과 참조한 아이콘 파일 존재 여부 확인.
- 현재 사용자용 `.pkg` 검사 통과. 배포 앱과 설치된 앱의 실행 파일 SHA-256 일치 확인.
- 서명된 앱 자체 검사: `composition_ok=true network_blocked=true errno=1`.
- 기존 ID를 유지한 채 0.5.1을 설치. 등록·활성화·선택 상태가 모두 true임을 확인했다.
- 설치 직후 사용자는 전환 표시가 여전히 비어 있다고 보고했다.
- `TextInputMenuAgent`와 `CursorUIViewService`를 다시 시작했다. 후자는 TERM 요청 뒤에도 실행 중이어서 해당 PID를 종료하고 새 프로세스를 확인했다. 다른 작업 앱은 종료하지 않았다.
- 서비스가 새로 시작된 뒤 사용자가 **이제 ‘순’이 보인다**고 확인했다.

이번 확인은 설정 보완과 표시 서비스 갱신을 함께 적용한 결과다. 세 설정 각각의 효과를
따로 측정하지 않았으며, 모든 macOS 버전에서 같은 방식으로 표시한다고 단정하지 않는다.
설치 스크립트가 시스템 표시 서비스를 자동으로 종료하지는 않는다.

입력 시험창에 사용자 입력이 함께 들어와 추가 타이핑 시험은 중단하고 창을 닫았다.
한글·Enter·삭제 코드는 바뀌지 않았으며, 직전 실제 입력 결과는
[0.5.0 검증 기록](INPUT-VERIFICATION-0.5.0.md)을 참고한다.
