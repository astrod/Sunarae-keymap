# Sunarae 0.5.4 (23) — 2026-10-10

## 변경과 확인 범위

글자 조회에 응답이 없다는 사실과 실제 문서 변경을 구분한다. 한글 키를 처리할 때 두 차례
조회가 실패하면 조합과 다음 키를 보관하고 8ms 뒤 다시 확인한다. 최대 세 차례 예약하며,
새 입력이 오면 더 일찍 확인할 수 있다. 이는 예약 간격이며 실제 실행 시각을 보장하지 않는다.
문자와 커서가 다시 맞으면 조합을 이어간다. 문서·커서 변경을 확인하면 이전에 보류한 키를
취소하여 새 입력창이나 선택 영역에 뒤늦게 쓰지 않는다. 새로 들어온 키는 현재 위치에 입력한다.
계속 조회에 실패하면 기다림을 끝내고 이전 범위를 덮어쓰지 않은 채 새 글자로 처리한다.
따라서 지속적인 조회 실패와 다른 원인에 의한 자모 분리까지 해결했다고 볼 수 없다.

## 자동 검사

- 조합·세션·편집 검사 269,449개, 메뉴·단축키 검사 통과.
- 조회 실패를 주입한 `걸로`, `설계` 복구와 Enter·삭제·커서·선택·문서 삭제·입력창 전환 검사 통과.
- 실제 메인 큐 예약을 사용하는 별도 NSTextView 시험 6개 통과.
  두 번의 누락은 약 8.7ms, 여섯 번의 누락은 약 27.1ms 뒤 `거 + ㄹ → 걸`로 복구했다.
  계속 실패하는 경우에는 약 27.0ms 뒤 `거ㄹ`로 기다림을 끝냈다. 추가 키 없이 진행한 결과다.
- 설치용 빌드와 앱 서명 검사, 앱 자체 검사 통과:
  `composition_ok=true network_blocked=true errno=1`.
- 릴리즈용 `make check package`에서도 269,449개, 메뉴·단축키, 설치·빌드 7개 및 앱 자체 검사 통과.
- 설치 파일을 풀어 버전·서명·현재 사용자 전용 설치·arm64·macOS 13 이상 조건을 확인했다.
  패키지의 실행 파일 SHA-256이 사용자가 확인한 설치본과 일치했다.

## 설치와 실제 키 시험

- 설치 위치: `~/Library/Input Methods/Sunarae.app`.
- 버전 0.5.4, 빌드 23. 빌드 결과와 설치된 실행 파일 SHA-256 일치:
  `c94f279128c304cf96f661cb02250516d974d1a243458764afb51584e3048231`.
- 이전 0.5.3 앱과 릴리즈 파일 백업: `build/backups/before-deferred-recovery.3mhhj4u6`.
- 입력기 등록·활성화와 설치 경로에서 새 프로세스 실행 확인.
- 별도 시험창에서 물리 키 입력 방식으로 `rjffh tjfrul rkk`와 Return을 입력했다.
  네이티브는 `- 걸로 설계 까\n`, 일반 웹과 Vim 삽입 모드는 각각
  `- 걸로 설계 까\n- `를 확인했다. 각 모드의 설치 확인용 시험이며 반복 스트레스 검사는 아니다.
- 두 웹 시험 모두 조합 이벤트 0개. Enter는 `keyCode=13`, `isComposing=false`였고
  편집기 조합 상태도 false였다.
- 재설치 후 최초 네이티브 시험은 영문으로 나왔다. 기본 두벌식과 순아래를 다시 선택한 뒤
  한글 입력과 Enter가 정상 동작했다. 웹 시험창도 처음에는 입력 소스를 찾지 못했으며,
  입력 소스 재선택 뒤 일반·Vim 시험을 마쳤다.
- 시험창을 종료하고 시험 전 ABC 선택을 복원했다. 입력기 프로세스는 설치 경로에서 실행 중이다.

자동 검사에서 조회 실패를 주입한 것과 실제 앱에서 같은 실패가 발생한 것은 다르다.
이번 실제 키 시험은 설치·기본 입력 동작을 확인하며, 사용자가 겪은 간헐적 오류의 원인이나
그 오류가 모든 앱에서 사라졌음을 입증하지 않는다.
2026-10-10 사용자가 실제로 써 보니 큰 문제가 없는 것 같다고 확인하고 릴리즈를 요청했다.
사용자가 확인한 앱·예문·횟수는 따로 보고받지 않았다. 배포 버전은 0.5.4, 빌드 23이며,
Apple Silicon용 설치 파일과 해당 커밋의 소스 ZIP, 두 파일의 SHA-256 목록을 함께 제공한다.
고정 예문 기록과 집계는 `tmp/recovery-check/installed-0.5.4-probe.jsonl`,
`tmp/recovery-check/installed-summary.json`에 보관했다.
